# Искажающий окуляр (Warping Ocular)
![icon.png](src/main/resources/assets/warping-ocular/icon.png)

> Задумывались ли вы о том, что в современном майнкрафте подзорная труба практически бесполезна? Данный мод стремится это исправить и сделать из неё юзабельный предмет.

## В рамках мода добавляется предмет, наследующий поведение ванильной подзорной трубы, но имеющий уникальные текстуры, модели и механики, а также способы его улучшать.

### Искажающий окуляр:
* Вокруг него построен мод🥶🤓
* Крафтится из подзорной трубы по середине, ока эндера в правом верхнем углу, по 1 железному слитку сверху и справа от трубы и редстоун пыли в левом нижнем углу.
* Внешне напоминает железную трубу с оком эндера поверх линзы
* Для использования необходимо зажать ПКМ, держа его в руке
* Смотря сквозь прицел, вы приблизите даль и станете видеть мир глазами эндермена
* Наведясь на интересующее вас место, нажмите ЛКМ для телепортации
* Необходимы эндер-пёрлы для активации
* После телепортации предмет уходит в 5 секундный кулдаун
* Вокруг вас появляются частицы
* Тратится прочность
* Со старта имеет 64 прочности
* Может быть зачарован на Прочность, Починку и Проклятие утраты
* Может быть починен на наковальне с помощью Осколка аметиста
* Может быть совмещён с другой трубой (ванильная возможность)

### Дальнозоркость I и II:
* Дополнительные зачарования для окуляра, позволяющие повышать возможную дистанцию телепортации с начальной 64 до 96 и 128 блоков соответственно
* Книга I уровня получается лорным крафтом (предварительно лазуритовой отделкой "Око" к книге).
* Зачарование II уровня получается совмещением 2 книг I уровня на наковальне/повторным применением книги I уровня на окуляр.

Мод работает на Fabric, начиная с версии Java 26.2, зависит от Fabric API.
